# NetDisk · Серверная часть корпоративного сетевого диска (open-source)

> Самостоятельно разворачиваемый (self-hosted) бэкенд сетевого диска для **совместной работы команд с файлами** (единственный исполняемый файл на Go).
> Предоставляет общие пространства команд, мультипротокольную загрузку TUS / WebDAV / multipart, версионированное финализирование,
> осведомлённость о синхронизации в реальном времени (SSE + курсор), детальные права доступа и управление квотами — может быть развёрнут как частное хранилище,
> так и служить файловым хабом предприятия.
>
> **Лицензия:** [Apache-2.0](LICENSE) · **Форма:** Community Edition (Server-com)

## ✨ Возможности

| Аспект | Возможности |
|---|---|
| 🚀 **Загрузка и финализация** | TUS дозагрузка по частям с восстановлением / WebDAV PUT / multipart — три точки входа используют общий путь финализирования; адресуемые по содержимому объекты + мгновенная загрузка с дедупликацией + проверка на «отравление» |
| 🧠 **Жизненный цикл объекта** | `file_objects` четыре состояния + объектный блокировщик (двухуровневый мьютекс); сначала запись объекта, затем короткая транзакция — исключает тихую перезапись и «дрейф» файлов |
| 💾 **Локальное объектное хранилище** | Хранилище, адресуемое по содержимому: объекты сохраняются на локальный диск по хешу содержимого, одинаковое содержимое хранится в одном экземпляре (дедупликация) |
| 📡 **Осведомлённость о синхронизации** | SSE push в реальном времени + курсор `/changes` в двух состояниях (глобальный `change_seq`), без периодического сканирования, совместно с настольным клиентом |
| 🔐 **Идентификация и права** | Собственная авторизация по логину и паролю + JWT (HS256), организации/отделы/группы, личное пространство / командное пространство, ссылки для общего доступа, сверка квот |
| 🗂 **Семантика каталогов** | Глубина каталога ≤31 / бюджет пути ≤240B; определение дубликатов без учёта регистра; разветвление MOVE/DELETE по порогу в асинхронную очередь |
| 🛡 **Эксплуатация и безопасность** | Сверка квот + инспекция объектов (утечки/осиротевшие) с исправлением; объектный блокировщик + ограничение частоты запросов к интерфейсу; аудит — зарезервированная заглушка (в данный момент не сохраняется) |
| 📦 **Панель администратора** | Панель администратора `/admin` (пользователи / организации / пространства / квоты), отдаваемая единым исполняемым файлом Go через `embed` |

## 🏛 Обзор архитектуры

```
                       ┌──────────────────────────────────────┐
  Веб-панель /admin ─▶│                                      │
  WebDAV-клиент  ─WebDAV▶│        netdisk (единый Go-бинарник)        │
  TUS-загрузчик      ─TUS─▶│   REST · TUS · WebDAV · SSE единая точка входа  │
  Клиент синхр. раб. стола  ─SSE──▶│                                      │
                       │   ┌──────────────────────────────┐   │
                       │   │ finalize — единственный путь записи + объектная блокировка   │   │
                       │   │ адресация по содержимому → локальное дисковое объектное хранилище     │   │
                       │   └──────────────────────────────┘   │
                       └───────────┬──────────────────────────┘
                                   │
                     ┌─────────────┼─────────────┐
                     ▼             ▼             ▼
               ┌──────────┐  ┌────────┐   ┌────────────┐
               │PostgreSQL│  │ Redis  │   │Nginx(прокси)│
               │  метаданные   │  │сессии/лимиты│   │   единый порт    │
               └──────────┘  └────────┘   └────────────┘
```

- **PostgreSQL 17 (минимально поддерживаемая)** —— единственный движок метаданных (включая WAL-архивирование); первичный ключ использует `gen_random_uuid()`, требуется PG ≥ 17
- **Redis** —— сессии / ограничение частоты / очередь задач (`SKIP LOCKED`, без внедрения MQ)
- **Nginx** —— реверс-прокси, единый порт наружу
- Фронтенд панели администратора после `pnpm build` в репозитории `web` копируется в `internal/webui/dist/` и отдаётся средствами **Go `embed`**

## 🚀 Быстрый старт

### Требования

- Go 1.26+
- PostgreSQL 17+ (минимум 17; БД: `netdisk` / `netdisk_test`, `LC_COLLATE=C`)
- Redis 7+ (`appendonly yes`, `noeviction`)
- Nginx (продакшен)

### 1. Сборка

```bash
# Окружение (внутреннее ускорение + отключение проверки)
export GOPROXY=https://goproxy.cn,direct
export GOSUMDB=off

go build ./...     # компиляция
go vet ./...       # статическая проверка
```

> **Примечание (embed):** если продукт фронтенда уже присутствует в `internal/webui/dist/`, он будет встроен при компиляции;
> после обновления фронтенда сначала выполните `pnpm build`, затем `go build`, иначе будет встроен устаревший продукт.

### 2. Миграция БД

```bash
go run ./cmd/migrate -dir internal/migrate/sql postgres "$NETDISK_DB_DSN" up
# либо с помощью уже собранного бинарника goose
```

### 3. Конфигурация

Скопируйте `deploy/config/config.example.yaml` в `config.yaml` и при необходимости измените.
**Все секретные настройки передаются исключительно через переменные окружения** (`NETDISK_JWT_SECRET` и др.; при отсутствии или слишком коротком значении запуск будет отклонён),
никогда не записываются в yaml — подробнее в `deploy/systemd/secrets.env.example`.

### 4. Запуск

```bash
go run ./cmd/netdisk
# слушает :8080
# /admin    панель администратора  /api/v1/*  REST  /dav/*  WebDAV  /changes   инкрементальная выборка  /sync/events  SSE
```

## 🔌 Возможности интерфейсов

| Точка входа | Описание |
|---|---|
| `REST /api/v1/*` | Аутентификация, пользователи, отделы, пространства, файлы, каталоги, загрузка, скачивание, общий доступ, события |
| `загрузка & Range` | Потоковая передача `ServeContent`; побайтовый Range (200/206/416); условные запросы If-Match/If-None-Match/If-Range |
| `TUS /uploads/*` | Фрагментация, дозагрузка, повторное использование ticket, очистка временной зоны, уровень диска (>90% → 507) |
| `WebDAV /dav/*` | `x/net/webdav` + перехват PUT через финализирование (≤100MB); семантика LOCK реализована самостоятельно |
| `SSE /sync/events` | Мгновенная push-доставка удалённых изменений (подавление собственного эха) |
| `cursor /changes` | Инкрементальная выборка курсором в двух состояниях, глобальный `change_seq` |
| Ограничение частоты | Градации file_read / file_write; при 429 нужен повтор |
